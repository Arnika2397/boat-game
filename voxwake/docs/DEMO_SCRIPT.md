# 3-minute judge demo

**Before:** Wispr Flow running and signed in · headphones · Chrome/Edge at 100% zoom · `npm start` running · notifications off · second laptop ready for the duel (optional).

| Time | Do | Say |
|---|---|---|
| 0:00 | Loading screen: the four rope signs drop in. Click **Tap to set sail** | "VOXWAKE: a boat race through Goa where your voice is the engine." |
| 0:15 | Title → **Play** → **Flow setup**. Hold Ctrl+Win and say "Goa is calling" (✓ *Looks like Wispr Flow*). Show the Snippets table (`vox nitro` → `[[nitro]]`) and the Goa dictionary **Copy all** | "Every Flow feature is a mechanic: bursts, snippets, dictionary, cleanup." |
| 0:40 | Championship → map → **Baga Shack Sprint** → postcard → race | |
| 0:50 | Speak the signs. Point at word pops, the streak ladder and the Flow ring. Say **"vox nitro"** when the chip glows (⚡ *via Flow snippet* toast) | "Stumbles and 'um's never cost you; Flow cleans them up." |
| 1:30 | Press **F8**: Flow Lens shows each burst → credited words → throttle gain | "Here's Flow driving the engine, live." |
| 1:50 | Results: **Flow stats** tab (words dictated vs typed, voice WPM, est. time saved), **Pit stop** (misheard words → copy to Flow dictionary), open a Tiffin Crate | |
| 2:15 | **Voice Duel** → Create room. Friend scans the QR with their webcam (or types the code) → both say "vox ready" → synced start | "Your friend joins from their own laptop." |
| 2:50 | Close | "Seven ways we use Wispr Flow: bursts, cleanup-tolerant matching, snippets, dictionary, paste-last recovery, hands-free long hauls, and live Flow stats." |

**If something fails:** no Flow → click **🎙 Browser mic** in the race, or type and press Enter. No mic at all → open `/?level=1&autopilot=1` (Demo autopilot) and say so honestly. Duel network trouble → use the code instead of the QR, or a phone hotspot.
